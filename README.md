# YOLO Object Detection

## Overview
Object detection project using YOLO11 and OpenCV.

## Technologies
- Python
- YOLO11
- Ultralytics
- OpenCV
- Google Colab

## Features
- Object detection in videos
- Video frame processing
- Detection visualization
- Output video generation

## Model
YOLO11n

## How to Run
1. Open the notebook in Google Colab.
2. Upload a video.
3. Run the notebook.
4. The detected video will be generated.
